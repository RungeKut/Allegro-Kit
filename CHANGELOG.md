## 2026-09-24 — Allegro-Kit 0.1.0

Первая версия. Всё ниже проверено на Cadence SPB 17.2-2016 S066.

* **Библиотека `alkit`**: пакетный режим (`run`, `dump`, `edit`, `place`)
  над копией платы; живой режим (`Live`) через `WM_COPYDATA` с
  транзакцией и откатом; диалоги Allegro (`allegro_dialogs`, `snapshot`,
  `press_default`); отчёты `report.exe` с разбором; экспорт Gerber,
  IPC-2581, STEP, PDF с проверкой содержимого; чтение схем Capture без
  Capture (`read_dsn`) по листам и вхождениям; картинка платы из выгрузки
  (`png`); проверки (`Report`, `check_board`, `compare`).
* **SKILL-часть** `alkit/skill/alkit.il`: выгрузка в JSON Lines
  (`akDumpBoard`), `akPlace`, `akText`, задание `akJob` со статусом через
  `errset`, проверкой открытой платы и транзакцией.
* **База знаний**: 10-01…10-05, 20-01…20-03, 30-01…30-10, 40-01, 40-02.
  Главные находки: кириллица и пробелы в пути ломают пакетный Allegro
  (падение или молча пустая плата); `exit` без `fillin no` вешает его;
  ошибки SKILL не останавливают сценарий; `WM_COPYDATA` теряет строки
  длиннее ~250 байт; утилиты экспорта пишут пустые или неполные файлы с
  кодом 0; обозначение корпуса в Capture — свойство `Reference`, а не
  `GetReferenceDesignator`; контур платы бывает объектом `polygon` без
  `->vertices`.
* **Оснастка**: `tools/setup.ps1` (UTF-8 с BOM), `check_docs.py` (плюс
  проверка испорченных таблиц индекса), хук `commit-msg`, два стоп-листа —
  публичный и локальный: приметы изделия больше не публикуются самим
  стоп-листом, как было в соседнем наборе.
* **Проверки** `tests/` на демо-паре из поставки Cadence; `test_live.py` —
  ручной, с открытым Allegro.
