# Allegro и Capture: платы и схемы скриптами

Набор — git-репозиторий, общий для нескольких машин. Корень находится так:
переменная `ALKIT_HOME`, иначе junction `~/.claude/skills/allegro`
(Claude Code) или `~/.kimi-code/skills/allegro` (Kimi Code) — ведут в
`<корень>/skill`.

## ОБЯЗАТЕЛЬНО: синхронизация репозитория

**В начале работы — подтянуть изменения.** Первым действием, до работы с
платой и до чтения базы:

```bash
cd "$ALKIT_HOME" && git pull --rebase
```

Конфликт — разобрать сразу: база знаний важнее текущей задачи.

**У владельца — заодно разобрать чужие правки.** Вклад без права записи
приходит pull request'ами, и они висят, пока владелец их не примет.
После `git pull`:

```bash
gh pr list                   # нет gh — REST API, см. 40-02
```

Открытый PR: прочитать diff целиком, прогнать `check_docs.py`, слить
rebase'ом, подтянуть слитое. Порядок и команды —
`knowledge/40_СРЕДА/40-02`.

**В набор не попадает ничего об изделии.** Репозиторий публичный. Ни в
файлах, ни в тексте коммита — ни названия, ни децимального номера, ни
номера платы, ни имён цепей и компонентов, ни чисел платы (сколько
компонентов, размер контура), ни надписей шелкографии, ни картинок платы,
ни путей, серверов и учётных записей. Примеры — на демо-платах Cadence или
на отвлечённой «шестислойной плате».

**После каждого изменения набора — отправить.** Сразу, не в конце сессии:

```bash
cd "$ALKIT_HOME"
git diff                                                # 1. прочитать глазами
python tools/check_docs.py --project "<папка проекта>"  # 2. стоп-слова
git add -A && git commit -m "кратко что и почему"       # 3. текст — тоже
git push
```

**Push отклонён с 403 / «Permission denied»** — право записи только у
владельца. Доступ не подбирать: изменение оформляется pull request'ом из
своего форка, правила обезличивания и проверки те же, что для коммита.
Порядок — `knowledge/40_СРЕДА/40-02`.

Приметы нового изделия вписываются в **`tools/stoplist.txt`** до первого
коммита. Этот файл **локальный**: он в `.gitignore`, его заводит
`setup.ps1` — стоп-лист в публичном репозитории сам опубликовал бы то,
что должен скрывать. Не возвращать его под git (ни `git add -f`, ни
копированием в отслеживаемый файл). Хук `commit-msg` проверяет текст
коммита. Описание узла, по которому изделие узнаётся без названия, не
ловит ничего — за этим `git diff` глазами. Подробности —
`knowledge/40_СРЕДА/40-02`.

**Автор коммитов — публичный, задан для клона** (`git config user.name` и
`user.email` без `--global`). Иначе git подставит глобальные рабочие имя и
адрес, и они уйдут в публичную историю — стоп-лист и хук этого не видят.
Не задан — не коммитить, а спросить человека, от какого имени публиковать.

**`gh auth login` из этой оболочки не запускать** — висит без терминала.
Проверять `gh auth status`; нет входа — просить человека.

## Версия Cadence: сверить до начала работы

База собрана на **Cadence SPB 17.2-2016, hotfix S066**. На другой версии
запись «проверено» читается как «не проверено», пока не подтверждена
(`knowledge/00_ПРАВИЛА.md`, раздел 11). Версия — `ak.version()`.

## Первое действие

```python
import os
import sys
sys.path.insert(0, os.environ["ALKIT_HOME"])
import alkit as ak

ak.utf8_console()          # иначе print с кириллицей упадёт
print(ak.version(), ak.product_order())
```

Резолвер пути без `ALKIT_HOME` — `templates/new_project/build.py`,
`kit_root()`.

## Три пути к Allegro

| Путь | Когда | Чем |
|---|---|---|
| **пакетный** | чтение и правка файла платы; Allegro не нужен открытым | `ak.dump`, `ak.place`, `ak.edit`, `ak.run` |
| **живой** | человек держит плату открытой и хочет видеть правку | `ak.Live()` → `.dump()`, `.run(code, edit=True)`, `.send("zoom fit")` |
| **утилиты** | отчёты и выходные файлы | `ak.summary`, `ak.drc`, `ak.unconnected`, `ak.unplaced`, `ak.gerber`, `ak.ipc2581`, `ak.step`, `ak.pdf` |

Схема Capture: `ak.read_dsn(path)` — Capture не нужен.

## Минимальный рабочий цикл

```python
src = r"D:\проект\плата.brd"                  # оригинал не трогается
b = ak.dump(src)                              # копия, Allegro без окна
print(b)                                      # компоненты, цепи, сегменты
ak.png(b, r"D:\проект\вывод\верх.png", side="top")

s = ak.read_dsn(r"D:\проект\схема.DSN")
ak.compare(s, b)                              # схема -> плата

dst = r"D:\проект\плата_v2.brd"              # результат — НОВЫМ файлом
ak.place(src, {"C11": (10.0, 20.0, 90, "top")}, save_to=dst)
b2 = ak.dump(dst)
ak.check_board(b2, expect_components=len(b.comps), max_drc=len(b.drcs))
ak.png(b2, r"D:\проект\вывод\верх_v2.png", side="top")
```

Единицы — **единицы платы** (`b.units`: millimeters, mils…). Набор их не
переводит; `b.to_mm(v)` — в миллиметры.

## Шесть правил, нарушение которых стоит часа

1. **Только над копией в папке без пробелов и кириллицы.** Иначе Allegro
   падает или молча открывает пустую плату, и скрипт «успешно» работает на
   ней. `alkit` копирует сам — не звать `allegro.exe` на пути человека.
2. **Успех — по статусу задания, журналу и файлам, не по коду возврата.**
   Ошибка SKILL сценарий не останавливает; экспорт с кодом 0 бывает пустым.
   `r.check()` или `Result.ok`.
3. **Сценарий кончается `exit` + `fillin no`, запуск — с тайм-аутом.**
   Иначе вечное ожидание вопроса о сохранении.
4. **Оригинал не перезаписывается.** `save_to` — новый файл;
   `overwrite=True` — только по явному решению человека. В живом режиме
   набор не сохраняет плату и не закрывает Allegro.
5. **Проверять числом из двух источников И глазами.** Выгрузка против
   отчёта, ожидание — не из Allegro; картинка — `ak.png`.
6. **Никогда не выдавать непроверенное за проверенное** — ни в коде, ни в
   отчёте, ни в базе знаний.
