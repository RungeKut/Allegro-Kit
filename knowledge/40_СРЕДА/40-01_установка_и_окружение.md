# Установка и окружение

## Состав

| Что | Где | Зачем |
|---|---|---|
| Cadence SPB 17.2-2016, hotfix S066 | `C:\Cadence\SPB_17.2` (ищется, не зашит) | Allegro, утилиты, tclsh, документация |
| Python 3.13, **64-bit** | любой | библиотека `alkit` |
| Pillow | `pip install Pillow` (ставит `setup.ps1`) | картинки платы, снимки диалогов |
| pywin32 | не нужен | окна и сообщения — через `ctypes` |

Корень Cadence ищется так: `ALKIT_CDSROOT` → `CDSROOT` →
`Sigrity_EDA_DIR` (её прописывает установщик SPB) → `C:\Cadence\SPB_*`.

## Переменные набора

| Переменная | Что | По умолчанию |
|---|---|---|
| `ALKIT_HOME` | корень набора (ставит `setup.ps1`) | — |
| `ALKIT_CDSROOT` | корень Cadence, если поиск не нашёл | поиск |
| `ALKIT_PRODUCT` | лицензии для пакетного режима, через запятую | `Allegro_performance, Allegro_Venture_PCB_Designer` из числа доступных |
| `ALKIT_WORK` | рабочие папки заданий; только ASCII, без пробелов | `%LOCALAPPDATA%\Temp\alkit` |

Лицензионный сервер задаёт установка Cadence (`CDS_LIC_FILE`), набор его
не трогает. Кэш доступных уровней —
`%HOME%\pcbenv\license_cache_allegro_17.2-2016.txt`
([30-06](../30_ГРАБЛИ/30-06_лицензии.md)).

## Что где в установке Cadence

| Путь | Что |
|---|---|
| `tools\bin\allegro.exe` | Allegro PCB Editor; `-nographic` работает и на Windows |
| `tools\bin\report.exe`, `artwork.exe`, `ipc2581_out.exe`, `step_out.exe`, `pdf_out.exe`, `dbdoctor.exe`, `extracta.exe` | утилиты над файлом платы ([10-04](../10_API/10-04_утилиты_отчёты_и_экспорт.md)) |
| `tools\bin\tclsh.exe`, `orDb_Dll_Tcl64.dll` | чтение схем Capture ([10-03](../10_API/10-03_схемы_capture_через_tcl.md)) |
| `share\pcb\examples\wm_copydata\allegro_sendcmd.c` | пример живого канала ([10-02](../10_API/10-02_живой_режим_wm_copydata.md)) |
| `share\pcb\examples\skill\` | примеры AXL-SKILL от Cadence |
| `share\orcad\examples\pcbdesign\pcbdemo1\` | демо-пара `DEMOJ.Dsn` + `allegro\DEMOJ-complete.brd` — на ней идут `tests\` |
| `doc\algroskill\` | справочник AXL (HTML), глава 2 — атрибуты объектов |
| `doc\sklangref\` | язык SKILL |
| `doc\orctclsample\`, `doc\orctclcap\` | TCL API Capture с примерами |
| `doc\algcmdref\` | команды строки Allegro |

Документация — HTML на тысячи страниц; для поиска её удобно один раз
перевести в текст (регулярка по тегам) и искать `grep`.

## Время

| Операция | Время |
|---|---|
| пакетный Allegro: открыть, задание, выйти | 4–7 с холодным, ~1 с повторно |
| полная выгрузка платы на ~15 000 сегментов | 7.5 с пакетно, 1.0 с в живом режиме |
| отчёт `report` | 0.4–1 с |
| чтение схемы на 21 лист | 0.6 с |
