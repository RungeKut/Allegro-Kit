# Пакетный режим

## Что происходит

На Windows `allegro.exe -nographic` работает без окна (документация пишет,
что ключ только для UNIX, — это не так). Запуск с открытием платы,
выполнением сценария и выходом занимает **4–7 с** холодным и около 1 с,
когда DLL уже в кэше.

## Как правильно

```
allegro.exe -nographic -product Allegro_performance
            -p C:\work\job1
            -s C:\work\job1\job.scr
            C:\work\job1\in.brd
```

* `-product` — имя лицензии (см. [30-06](../30_ГРАБЛИ/30-06_лицензии.md)).
  Без него 17.2 показывает окно выбора продукта и ждёт вечно.
* `-p` — папка для журнала `allegro.jrl` и прочих файлов. Без неё Allegro
  переходит в папку платы и пишет туда — в папку проекта человека.
* `-s` — **абсолютный** путь сценария: из-за перехода в папку платы
  относительный теряется, и Allegro ждёт команд вечно
  ([30-02](../30_ГРАБЛИ/30-02_пути_кириллица_пробелы.md)).
* Плата — **копия** на пути без пробелов и кириллицы.

Сценарий `.scr`:

```
version 17.2
skill load("C:/work/job1/job.il")
exit
fillin no
```

`fillin no` отвечает «нет» на вопрос о сохранении, который `exit` задаёт
при несохранённых правках; без него процесс висит
([30-01](../30_ГРАБЛИ/30-01_exit_без_fillin_no.md)). Если вопроса не было,
строка просто не читается.

Весь смысл — в `job.il`. Сохранять плату — из SKILL:

```lisp
axlSaveDesign(?design "C:/work/job1/out" ?noConfirm t)   ; без .brd
```

В `alkit` это собрано в `ak.run()`; поверх — `ak.dump()`, `ak.place()`,
`ak.edit()`.

## Что где видно

| Источник | Что в нём |
|---|---|
| код возврата | 0 почти всегда; 2 — «No licenses available»; `-1073741819` (0xC0000005) — падение на плохом пути. Об успехе задания не говорит ничего |
| stdout | консоль Allegro: `E- *Error* ...` для ошибок SKILL, результат `t`/`nil` каждой строки `skill` |
| `allegro.jrl` в папке `-p` | `Design opened: <путь>` — **главная проверка**, что открыта нужная плата; `*Error*` и строки `\e (…)` — ошибки |
| файлы, написанные кодом | результат задания; писать в папку задания |

Ошибка SKILL сценарий не останавливает ([30-04](../30_ГРАБЛИ/30-04_ошибки_skill_не_останавливают.md)),
поэтому итог задания пишет сам код (в `alkit` — `akJob` в
`alkit/skill/alkit.il`: статус OK/ERR через `errset` и маркер `done`).

## Как неправильно

```
allegro.exe -nographic -s job.scr "D:\Проекты\Плата 1\плата.brd"
```

Три ошибки сразу: нет `-product` (окно выбора, вечное ожидание),
относительный сценарий, кириллица и пробелы в пути (падение или пустая
плата). Итог — зависший процесс без единой строки в журнале.

## Чем подтверждено

24.09.2026: чтение сводки демо-платы (351 компонент, 371 цепь) за 4.4 с;
полная выгрузка фигур за 7.5 с; правка трёх компонентов с сохранением и
перечиткой; `exit` без `fillin no` при правке — зависание, снято по
тайм-ауту; с `fillin no` — выход за 4 с.
