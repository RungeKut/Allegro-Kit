# Живой режим

## Что происходит

Запущенный Allegro принимает строку команд (как в своей командной строке)
сообщением `WM_COPYDATA`:

* `dwData` = `0x26297811` (MAGIC из примера Cadence), иначе сообщение
  игнорируется;
* `lpData` — 8-битная строка с завершающим нулём. **cp1251** на русской
  Windows: путь с кириллицей внутри `skill load("…")` проходит;
* `SendMessage` возвращает 1 сразу — **выполнилась команда или нет, не
  сообщается**. Allegro берёт строку, когда освободится.

Любая команда: `zoom fit`, `skill load("C:/…/job.il")`,
`skill (akDumpBoard "…")`.

## Как правильно

Протокол `alkit.Live`:

1. Код задания пишется в файл в короткой рабочей папке
   (`%LOCALAPPDATA%\Temp\alkit\live-…`), там же `alkit.il` и `job.il`.
2. Посылается одна короткая строка `skill load("<папка>/job.il")`.
3. `job.il` выполняет код в `errset`, при `edit=True` — в транзакции
   (`axlDBTransactionStart` → `Commit` или `Rollback` при ошибке), пишет
   `status.txt` и потом маркер `done`.
4. Python ждёт `done` с тайм-аутом и читает статус.

```python
import alkit as ak
lv = ak.Live()                                  # окно «Продукт: плата.brd»
b = lv.dump()                                   # около 1 с на демо-плате
r = lv.run('akPlace("C11" 12.0 22.0)', edit=True)
r.check()
lv.send("zoom fit")
```

Окно ищется по заголовку вида `Allegro PCB Designer: плата.brd  Project: …`.
Главное окно без открытой платы называется
`Allegro PCB Designer 17.2 (S066)`, диалог — просто `Allegro PCB Designer`.

Отправка — `SendMessageTimeoutW` с `SMTO_ABORTIFHUNG`: пока открыт
модальный диалог, обычный `SendMessage` не возвращается совсем.

## Как неправильно

* Посылать сам код SKILL строкой: длиннее ~250 байт — молча теряется
  ([30-05](../30_ГРАБЛИ/30-05_wm_copydata_предел_и_диалоги.md)).
* Искать окно по подстроке «Allegro», как пример Cadence: первым может
  попасться модальный диалог с тем же словом в заголовке.
* Слать `exit`: откроется вопрос о сохранении, ответить на него каналом
  нельзя, процесс остаётся висеть с диалогом.
* Судить об успехе по возврату `SendMessage` — он 1 всегда.

## Чем подтверждено

24.09.2026, демо-плата в открытом Allegro PCB Designer: выгрузка 14926
сегментов за 1.0 с; `akPlace` в транзакции за 0.08 с, перечитка показала
новые координаты; код с ошибкой после `akPlace` — статус ERR, компонент
остался на прежнем месте (откат сработал); команда
`skill …(«C:/…/Кир/вывод.txt»)`, посланная в cp1251, создала файл в папке
с кириллическим именем.
