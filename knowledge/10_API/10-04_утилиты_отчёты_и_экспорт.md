# Утилиты: отчёты и экспорт

Все утилиты работают над файлом платы без запуска Allegro, за 0.1–2 с.
Запускать над копией в папке без пробелов и кириллицы, рабочая папка
процесса — папка копии: туда падают выходные файлы и журналы.

## Отчёты: report.exe

```
report -v <код> in.brd out.txt        # список кодов: report -help
```

| Код | Что | Разбор в alkit |
|---|---|---|
| `sum` | сводка: слои, символы, DRC, полигоны, сверловка | `ak.summary()` → словарь |
| `drc` | нарушения, CSV после строки `Constraint Name` | `ak.drc()` → список |
| `ucn` | `Total Unconnected Pin Pairs: N` | `ak.unconnected()` |
| `upc` | `Total Unplaced Components: N` | `ak.unplaced()` |
| `bom`, `cmp`, `net`, `pad`, `x-section` … | остальные | `ak.report(path, код)` → текст |

Числа отчётов — независимая сверка к выгрузке SKILL: DRC из `sum`, из
`drc` и из `axlDBGetDesign()->drcs` совпали.

## Экспорт

| Что | Командная строка | Где результат | Подвох |
|---|---|---|---|
| Gerber | `artwork in.brd`; `artwork -l in.brd` — список плёнок | `<префикс>-<плёнка>-<суффикс>.art` в рабочей папке, журнал `photoplot.log` | код **1** при любых предупреждениях, файлы при этом есть; плёнки должны быть заданы в плате |
| IPC-2581 | `ipc2581_out -u MILLIMETER -b -l -R -n -p -t -c -O -I -S -k -o out in.brd` | `out.xml`, `ipc2581_out.log` | **без ключей разделов — пустая оболочка 1.8 КБ с кодом 0** |
| STEP | `step_out -u MILLIMETER -m -n -o out.stp in.brd` | `out.stp`, `step_out.log` | без `-m -n` — только плата; незамкнутый контур выбрасывается с WARNING и кодом 0 |
| PDF | `pdf_out in.brd -o out.pdf` | путь — в строке `Output file:` вывода | к имени приклеиваются глобальные приставки плёнок: `JOBNAME-_out_-ISSUEA.pdf` |

Все четыре подвоха собраны в [30-07](../30_ГРАБЛИ/30-07_экспорт_код_возврата_врёт.md).
В `alkit` — `ak.gerber()`, `ak.ipc2581()`, `ak.step()`, `ak.pdf()`: каждая
сама проверяет содержимое (компоненты в XML, выброшенный контур в журнале
STEP, наличие файла каждой плёнки).

## Не проверено

* сверловка (NC drill) без GUI: утилиты `ncroute`, `nctape`, `ncrun` есть в
  `tools/bin`, но не запускались;
* `dbdoctor -drc_only` (пересчёт DRC над файлом) — не запускался;
* `extracta` с файлом представления — справка прочитана, не запускался.

## Чем подтверждено

24.09.2026, демо-плата: 13 плёнок Gerber (код 1, 7 предупреждений);
IPC-2581 с ключами — 3 МБ, 352 `<Component`; без ключей — 1.8 КБ пустой
оболочки; STEP с `-m -n` — 773 КБ; PDF — 2.1 МБ под именем с приставками.
Шестислойная плата с разрывом контура 0.001 мм: STEP выбросил 14 элементов
контура, код 0.
