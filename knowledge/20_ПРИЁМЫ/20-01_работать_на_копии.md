# Работать на копии

## Правило

1. Плата (и схема) копируется в свежую папку задания
   `%LOCALAPPDATA%\Temp\alkit\<вид>-<дата>-<время>-<n>` под именем
   `in.brd` / `in.dsn`.
2. Allegro, утилиты и tclsh работают только с копией.
3. Результат правки сохраняется в папке задания как `out.brd`, и Python
   копирует его туда, куда попросили, — любой путь, хоть с кириллицей.
4. Существующий файл не перезаписывается без явного `overwrite=True`.
   Оригинал платы правится только решением человека.

`ak.run()`, `ak.dump()`, `ak.place()`, отчёты, экспорт и `ak.read_dsn()`
делают это сами. Папки заданий хранятся (последние 40) — в них журнал,
код задания и промежуточные файлы для разбора.

## Почему так

Каждая причина — отдельная потерянная попытка:

* путь с кириллицей или пробелом: пакетный Allegro падает или молча
  открывает пустую плату ([30-02](../30_ГРАБЛИ/30-02_пути_кириллица_пробелы.md));
* убитый по тайм-ауту процесс оставляет `.lck` — на оригинале он помешал
  бы и человеку ([30-03](../30_ГРАБЛИ/30-03_брошенная_блокировка.md));
* Allegro пишет журнал, `master.tag`, `signoise.run/` в папку платы — в
  папку проекта человека, если работать на месте;
* правка, упавшая на середине, не может испортить оригинал.

Копия платы в несколько мегабайт стоит миллисекунды.

## Живой режим — исключение

Там плата уже открыта человеком. Правка идёт в транзакции (ошибка —
откат), а **сохранение остаётся человеку**: набор не сохраняет и не
закрывает чужой сеанс.

## Как неправильно

```python
ak.run(r"D:\Проекты\Плата 1\плата.brd", code)        # это правильно:
# run сам скопирует. Неправильно — звать allegro.exe на этом пути напрямую
subprocess.run(["allegro.exe", "-nographic", ..., r"D:\Проекты\Плата 1\плата.brd"])
```
