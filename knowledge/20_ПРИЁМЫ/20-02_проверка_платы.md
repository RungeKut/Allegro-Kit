# Проверка платы

## Правило

После любого действия с платой — три проверки, каждая ловит своё:

| Проверка | Чем | Что ловит |
|---|---|---|
| задание подтвердило успех | `Result.ok` / `r.check()`: статус OK от `akJob`, `Design opened:` копии, все выходные файлы | работу на пустой плате, ошибки SKILL, недописанный файл |
| числа | выгрузка `ak.dump()` + `ak.check_board()`; отчёты `ak.summary()`, `ak.drc()`, `ak.unconnected()`, `ak.unplaced()` | не то количество, сдвиг не в тех единицах, новые DRC, разорванные связи |
| глаза | `ak.png(b, …, side="top"/"bottom")` | компонент не на той стороне, «правильные» числа при неправильной картине |

Числа берутся **из двух независимых источников**: выгрузка SKILL и отчёт
`report.exe` считают по-разному, и их совпадение — проверка самой
выгрузки. На шестислойной плате DRC совпали в трёх местах: `sum`, `drc`,
`axlDBGetDesign()->drcs`.

## Как правильно

```python
import alkit as ak

r = ak.place(src, {"C11": (10.0, 20.0, 90, "top")}, save_to=dst)  # r.check() внутри
b = ak.dump(dst)
rep = ak.Report("после расстановки")
s = b.sym("C11")
rep.close_to("C11 X", s["xy"][0], 10.0, tol=1e-3)
rep.close_to("C11 Y", s["xy"][1], 20.0, tol=1e-3)
rep.close_to("C11 угол", s["rot"], 90.0, tol=1e-6)
rep.equal("C11 на нижней стороне", bool(s["mirror"]), False)
rep.at_most("нарушений DRC", len(ak.drc(dst)), len(ak.drc(src)))
rep.done()
ak.png(b, "после.png", side="top")
```

Ожидание берётся **не из Allegro**: из заказа, из схемы, из расчёта.
Сверка платы со схемой — [20-03](20-03_сверка_схемы_с_платой.md).

## Что не проверяется

* DRC в выгрузке и отчётах — те, что сохранены в плате. Если после правки
  DRC не пересчитывался (`drcState` в выгрузке не `t`), число устарело.
  Пересчёт без GUI (`dbdoctor -drc_only`) не проверялся.
* Картинка упрощает: дуги — хордами, площадки — габаритом вывода.

## Чем подтверждено

24.09.2026: цикл выше на демо-плате (перенос, поворот, смена стороны —
перечитка совпала с заказом); на шестислойной плате картинка низа
показала DRC-метки ровно там, где их перечислил отчёт `drc`.
