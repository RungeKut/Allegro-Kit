# Ёмкость между доменами земли по меди платы

## Что происходит

Вопрос «насколько на самом деле развязан изолированный узел» (гальваническая
развязка по питанию и данным есть, а ёмкость на основную землю — сотни пФ и
больше) решается только геометрией: где под полигонами изолированного домена
на соседних слоях лежит медь основного. Две ловушки на пути:

* `ak.dump` отдаёт у полигона **только внешний контур** (`akShapePts` берёт
  `car(axlPolyFromDB(s))->vertices`). Вырезы (voids) теряются, и перекрытие по
  такой выгрузке завышено — сплошная плоскость с вырезом под чужой зоной
  выглядит сплошной.
* Толщины диэлектриков в выгрузке нет. Они есть в отчёте `x-section`.

## Как правильно

Полигоны с вырезами — отдельным заданием (`ak.run`, в `akOut`):

```lisp
axlVisibleDesign(t)
axlClearSelSet()
axlSetFindFilter(?enabled list("noall" "shapes") ?onButtons list("noall" "shapes"))
axlAddSelectAll()
foreach(s axlGetSelSet()
  when(s->objType == "shape" && substring(s->layer 1 4) == "ETCH"
    foreach(pl axlPolyFromDB(s)             ; ?holes по умолчанию t
      ; pl->area — площадь за вычетом вырезов
      ; pl->vertices — внешний контур, пары ((x y) радиус)
      ; pl->holes    — список o_polygon вырезов, у каждого ->vertices
      ...)))
axlClearSelSet()
```

Стек — `ak.report(плата, "x-section")`: CSV-строки
`Subclass Name,Type,Material,Thickness,…,Dielectric Constant,…`; строки
`DIELECTRIC` без имени лежат между слоями меди в порядке сверху вниз.

Оценка ёмкости: сетка с шагом 0,25 мм по зоне домена; в каждой точке — какая
медь (слой, цепь) лежит на каждом слое; для соседних по вертикали слоёв с
медью, из которых один свой, другой чужой, — плоский конденсатор
`ε0·εr·dA/h`, где `h` — сумма диэлектриков между ними. Медь между ними
экранирует — поэтому только ближайшие соседи, а не все пары слоёв. Для
проводников (не полигонов) плоская формула занижает ёмкость в 2–3 раза из-за
краевого поля.

Геометрию удобно считать `shapely` (`Polygon(контур, [вырезы]).buffer(0)`);
дуги в контуре допустимо заменить хордами.

## Как неправильно

* Считать перекрытие по `bbox` полигонов или по `pts` из `ak.dump` —
  вырезы не учтены, ответ завышен.
* Сравнивать только слои «PLANE»: заливка земли на сигнальном слое между
  плоскостями изолированного домена даёт основную долю ёмкости, и её
  легко не заметить.
* Взять пары «каждый слой с каждым»: промежуточная медь экранирует, сумма
  выйдет завышенной.

## Чем подтверждено

24.09.2026: задание выше отработало пакетно без ошибок, у полигонов пришли
вырезы (`H`-строки), `->area` совпала с площадью `shapely` за вычетом
вырезов (у большинства полигонов — точно; у мелких с дугами расхождение
до ~12 % — дуги заменены хордами). У крупной плоскости с вырезами площадь
по внешнему контуру оказалась на ~10 % больше `->area`. Картинка внутренних слоёв в зоне развязанного узла
подтвердила найденное сеткой: заливка основной земли на сигнальном слое
лежит между землёй и питанием изолированного домена.
