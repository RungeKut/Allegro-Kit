# Пределы живого канала

## Что происходит

**1. Длина.** Команды `skill akProbe("<путь>")` разной длины, каждая с
паузой 1.5 с:

| Длина строки | Выполнена |
|---|---|
| 218, 248 символов | да |
| 259, 269, 279, 299, 359 | **нет** — при том что `SendMessage` вернул 1 |

**2. Модальный диалог.** Посланный `exit` открыл в GUI вопрос о
сохранении; обычный `SendMessage` не вернулся 67 с — до снятия процесса.
Посланный вслед `fillin no` доставлен (возврат 1), но на диалог не
повлиял. То же при открытии платы старого формата: GUI ждёт ответа
([30-09](30-09_старая_плата_и_обновление_формата.md)), и до ответа канал
бесполезен.

**3. Поиск окна.** Пример Cadence ищет первое окно, в заголовке которого
есть «Allegro». Диалоги называются `Allegro PCB Designer` — пример
попадает в них.

## Как правильно

* Слать только `skill load("<короткий путь>/job.il")`; код — в файле.
  Рабочая папка короткая (`%LOCALAPPDATA%\Temp\alkit\…`), `Live.send`
  отвергает строки длиннее 250 байт до отправки.
* `SendMessageTimeoutW` с `SMTO_ABORTIFHUNG` и тайм-аутом: не дождались —
  Allegro занят (`AllegroBusy` в alkit).
* Главное окно — видимое, с заголовком по шаблону
  `^<продукт>: <плата>.(brd|dra|mcm|sip|pad)`.
* Перед работой — `lv.dialogs()`: непустой список значит, что канал
  заблокирован. Если `ak.Live()` не создаётся (окна с платой ещё нет) —
  `ak.allegro_dialogs()`. Прочитать диалог — `ak.Live.snapshot(hwnd,
  png)`; ответить кнопкой по умолчанию — `ak.Live.press_default(hwnd)`
  (адресный Enter через `PostMessage`, проверено на диалоге обновления
  формата).
* Не слать `exit`: закрывать GUI — дело человека.

## Как неправильно

```python
send(hwnd, 'skill load("…") akDumpBoard("…/dump.jsonl" t)')  # 270 байт — потеряна
send(hwnd, "exit")                                            # диалог, канал встал
```

## Чем подтверждено

24.09.2026: таблица длины — по наличию выходного файла каждой команды;
`exit` — вызов висел 67 с; диалог обновления формата 16.6 закрыт
`PostMessage(WM_KEYDOWN/WM_KEYUP, VK_RETURN)`, плата открылась.
