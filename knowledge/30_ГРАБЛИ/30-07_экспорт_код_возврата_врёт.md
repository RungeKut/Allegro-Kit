# Экспорт: код возврата врёт

## Что происходит

| Утилита | Вызов | Код | Что на самом деле |
|---|---|---|---|
| `ipc2581_out` | `-u MILLIMETER -o ipc b.brd` | 0 | файл 1.8 КБ: словари и шапка, **ни одного компонента, слоя, цепи**. В журнале все разделы «Export …?: NO» |
| `step_out` | `-u MILLIMETER -o b.stp b.brd` | 0 | только плата, без компонентов (разделы «parts … NO») |
| `step_out` | на плате с разрывом контура 0.001 мм | 0 | в журнале 14 × `WARNING: Discarding unconnected item on Board Geometry / Outline` — **контур выброшен**, тела платы в STEP нет |
| `artwork` | `artwork b.brd` | **1** | все 13 плёнок созданы; код 1 — «ARTWORK had warnings» |
| `pdf_out` | `b.brd -o out.pdf` | 0 | файла `out.pdf` нет: создан `JOBNAME-_out_-ISSUEA.pdf` — к имени приклеены глобальные приставки плёнок платы |

## Как правильно

* IPC-2581 — с ключами разделов:
  `-b -l -R -n -p -t -c -O -I -S -k`; проверять, что в XML есть
  `<Component`.
* STEP — с `-m -n` (компоненты с моделями и без); читать журнал на
  `Discarding unconnected item on Board Geometry` и считать это браком
  контура платы (`ak.step(..., strict=True)` — исключение).
* Gerber — успех определять по наличию файла **каждой** плёнки из
  `artwork -l`, а не по коду.
* PDF — путь брать из строки `Output file:` вывода `pdf_out`.

Всё это делают `ak.ipc2581`, `ak.step`, `ak.gerber`, `ak.pdf`.

## Как неправильно

```python
subprocess.run(["ipc2581_out", "-o", "board", "b.brd"], check=True)
# «успех», а файл пуст
```

## Чем подтверждено

24.09.2026: таблица выше; с ключами IPC-2581 демо-платы — 3 МБ и 352
`<Component`; STEP с `-m -n` — 773 КБ против 21 КБ без них; причина
выброшенного контура видна по координатам в том же журнале: концы двух
соседних дуг расходятся на 0.001 мм.
