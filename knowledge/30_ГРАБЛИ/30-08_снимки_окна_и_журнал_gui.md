# Снимки окна и журнал GUI

## Что происходит

* `PrintWindow(hwnd, …, PW_RENDERFULLCONTENT)` снимает окно Allegro целиком
  — меню, панели, списки слоёв, — но **холст платы белый**: он рисуется
  аппаратно, мимо GDI.
* `PIL.ImageGrab.grab(bbox=…)` по области окна упал с
  `OSError: screen grab failed`. Причина не выяснена; вероятно,
  заблокированный экран или недоступный рабочий стол сеанса.
* Журнал `allegro.jrl` открытого GUI во время работы имеет размер 0:
  буфер сбрасывается при выходе. Ошибки живого режима по журналу не
  увидеть — только через файлы, которые пишет код задания.

Диалоги (Qt-окна без аппаратной отрисовки) `PrintWindow` снимает
нормально — так читается вопрос, заблокировавший канал
([30-05](30-05_wm_copydata_предел_и_диалоги.md)).

## Как правильно

Картинка для проверки глазами рисуется по данным выгрузки:

```python
b = ak.dump(path)                 # или Live().dump()
ak.png(b, "верх.png", side="top")
ak.png(b, "низ.png", side="bottom")
```

Работает и в пакетном режиме, без окна и без экрана; не зависит от того,
какие слои человек включил в GUI.

## Как неправильно

Проверять результат снимком окна: белый прямоугольник выглядит как
«ничего не нарисовалось» и уводит отладку в сторону.

## Чем подтверждено

холст белый; снимок диалога обновления формата — текст читается;
`ImageGrab` — `screen grab failed`; `allegro.jrl` сеанса — 0 байт при
выполненных командах.
