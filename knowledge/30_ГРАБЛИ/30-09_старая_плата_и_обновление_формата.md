# Старая плата: обновление формата

## Что происходит

Демо-плата из поставки сохранена в 16.6. При открытии в GUI 17.2:

```
The design created using release '16.6' will be updated for compatibility
with the current software. Once saved, the design will be accessible only
from the current or later versions of Cadence software. Click Yes to proceed.
                                                          [ Да ]  [ Нет ]
```

Пока вопрос висит, главное окно называется
`Allegro PCB Designer 17.2 (S066)` (без имени платы), `ak.Live()` его не
находит, а команды `WM_COPYDATA` не выполняются.

В пакетном режиме (`-nographic`) та же плата открывается **без вопроса**,
задание выполняется, `axlSaveDesign` пишет файл.

## Почему

Allegro обновляет структуру базы в памяти при открытии. GUI спрашивает,
потому что сохранённый файл станет недоступен старым версиям; пакетный
режим спросить не может и соглашается.

## Как правильно

* Помнить, что **сохранённая пакетом копия — уже в формате текущей
  версии**. Для машин со старым Allegro она непригодна; оригинал набор не
  трогает ([20-01](../20_ПРИЁМЫ/20-01_работать_на_копии.md)).
* В живом режиме, если `ak.Live()` не находит окно, — смотреть
  `ak.allegro_dialogs()` (диалоги всех процессов allegro.exe; `Live()` в
  этот момент создать нельзя), читать диалог `ak.Live.snapshot(hwnd,
  png)`, решение о «Да» — за человеком или `ak.Live.press_default(hwnd)`
  после прочтения.

## Как неправильно

Открыть в GUI плату старого формата скриптом и сразу слать команды:
они уходят в никуда, пока висит вопрос.

## Чем подтверждено

24.09.2026, дважды: демо-плата 16.6 в GUI — диалог выше (снят
`Live.snapshot`), `ak.allegro_dialogs()` его нашёл, после
`press_default` плата открылась и `tests/test_live.py` прошёл; та же плата
через `ak.dump` и
`ak.place` — без вопросов, правка сохранена. Открытие сохранённой копии в
16.6 не проверялось — старой версии на машине нет.
