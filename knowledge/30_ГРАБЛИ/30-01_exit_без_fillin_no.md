# exit без fillin no

## Что происходит

Сценарий правит плату и не сохраняет её, последняя строка — `exit`.
Allegro без окна задаёт вопрос «Do you want to save the changes you made
to …?» и ждёт ответа вечно: ни ошибки, ни вывода, процесс жив.

## Почему

`exit` в Allegro интерактивен и при несохранённых правках спрашивает.
В GUI ответ даёт человек (в журнале остаётся `fillin no`), в пакетном
режиме — некому.

## Как правильно

```
version 17.2
skill load("C:/work/job1/job.il")
exit
fillin no
```

Если правок нет или плата сохранена, вопроса нет и лишняя строка не
читается — вреда от неё нет. И всё равно запускать с тайм-аутом: зависнуть
можно и на другом вопросе.

## Как неправильно

```
version 17.2
skill load("C:/work/job1/job.il")
exit
```

## Чем подтверждено

24.09.2026: текст, добавленный в транзакции без сохранения, + `exit` —
процесс висел до снятия по тайм-ауту 40 с. Тот же сценарий с `fillin no`:
в журнале `\e … Do you want to save the changes you made to board.brd?`,
затем `\i … fillin no`, выход, код 0.
